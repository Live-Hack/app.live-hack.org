# Security policy

Please report vulnerabilities in the Live Hack code privately, through GitHub's
"Report a vulnerability" button on this repository (Security tab). Do not open a public issue.

Include a description, the affected version or commit, and steps to reproduce.
We will acknowledge the report, fix it, and credit you if you wish.

This policy covers the source code. Each platform running Live Hack is operated by its own host;
contact that host for issues with their deployment (see `/.well-known/security.txt` on their site).
